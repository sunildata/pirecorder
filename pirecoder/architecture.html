5 · API Surface
Method Path Purpose Notes
GET / Serve UI Renders index.html via Flask template
GET /api/status Polling status Returns is_recording, current_file, duration
POST /api/start Start recording JSON body: { "label": "..." } (optional) · 400 if already recording
POST /api/stop Stop & save WAV Signals thread, joins (5 s timeout), writes WAV · 400 if not recording
GET /api/recordings List files Returns array of { name, size_kb }, sorted newest-first
GET /api/download/<filename> Download WAV Sent as attachment · 404 if missing
DELETE /api/delete/<filename> Delete WAV Unlinks file · 404 if missing
WS status event Live push Emitted on connect, start, stop, and each chunk read in worker

8 · Design Constraints
  • 🔒No auth — designed for trusted LAN use only; cors_allowed_origins="*"
  • 1️⃣One recording session at a time — /api/start returns 400 if is_recording=True
  • 💾In-memory buffer — all PCM frames held in _frames[] until stop; no streaming to disk mid-recording
  • 🗄No database — recordings are plain files in recordings/; inventory is a live directory scan
  • ⚙️No build tooling — frontend is a single .html template; no npm, webpack, or transpilation
  • 🔑Hardcoded SECRET_KEY — fine for LAN, must be changed for any public deployment

10 · How to Run on Raspberry Pi
① What you need before starting
🖥
Raspberry Pi OS
Bullseye or Bookworm (32-bit or 64-bit). Run cat /etc/os-release to check.
🐍
Python 3.9+
Pre-installed on Pi OS. Verify: python3 --version
🎤
USB Microphone
Plug in before booting. Check it's detected: arecord -l
📶
Wi-Fi connected
Pi and your phone must be on the same Wi-Fi network.
📁
Project files on Pi
app.py, requirements.txt, templates/index.html already transferred.
🌐
Internet access (first run)
Needed to apt install and pip install dependencies.
② Install system dependencies

Run these in the terminal on your Pi (SSH or directly).

Update package list
$ sudo apt update
Install PortAudio (required by PyAudio) + Python venv
$ sudo apt install -y portaudio19-dev python3-venv python3-pip
Verify mic is visible to ALSA
$ arecord -l
Expected output: card N: USB Audio [USB Audio], device 0: USB Audio [USB Audio Analog Stereo]
③ Create virtual environment & install Python packages

Do this once inside the project folder.

Go to your project folder (adjust path as needed)
$ cd ~/pirecoder
Create a virtual environment
$ python3 -m venv venv
Activate it (you must do this every new terminal session)
$ source venv/bin/activate
Prompt changes to: (venv) pi@raspberrypi:~/pirecoder $
Install all Python dependencies from requirements.txt
$ pip install -r requirements.txt
Installs: Flask 3.0.3 · flask-socketio 5.3.6 · pyaudio 0.2.14 · eventlet 0.36.1
Verify installation
$ pip list | grep -E "Flask|pyaudio|eventlet"
④ Run the app
Make sure venv is active, then start the server
$ python app.py
Expected: * running on http://0.0.0.0:5000
Find your Pi's IP address (open a second terminal)
$ hostname -I
Example output: 192.168.1.42
Keep the terminal open. Closing it stops the server. Use systemd (Step ⑥) or tmux / screen to keep it running after you close SSH.
Run in background with tmux (optional, keeps running after SSH disconnect)
$ tmux new -s recorder
$ source venv/bin/activate && python app.py
Detach with Ctrl+B then D · Re-attach with: tmux attach -t recorder
⑤ Open from your phone
1
Connect your phone to the same Wi-Fi as the Pi
2
Open any browser (Chrome, Safari, Firefox)
3
Go to http://<PI_IP>:5000
e.g. http://192.168.1.42:5000
4
Tap Start Recording — Pi's mic begins capturing
5
Tap Stop — WAV saved to recordings/ on the Pi
6
Tap a recording to download it directly to your phone
Tip: On Android/iOS you can "Add to Home Screen" in your browser menu to get an app-like shortcut — no app store needed.
⑥ Autostart on boot with systemd (optional)

After this the recorder starts automatically every time the Pi boots — no SSH needed.

Create the service file
$ sudo nano /etc/systemd/system/audio-recorder.service
Paste this content (adjust paths to match your setup)
[Unit]
Description=Pi Audio Recorder
After=network.target

[Service]
User=pi
WorkingDirectory=/home/pi/pirecoder
ExecStart=/home/pi/pirecoder/venv/bin/python app.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
Enable and start the service
$ sudo systemctl daemon-reload
$ sudo systemctl enable audio-recorder
$ sudo systemctl start audio-recorder
Check it's running
$ sudo systemctl status audio-recorder
Expected: ● audio-recorder.service - Pi Audio Recorder ... active (running)
View live logs
$ journalctl -u audio-recorder -f
Done! From now on, just power on the Pi and open http://<PI_IP>:5000 from any phone on your Wi-Fi.
